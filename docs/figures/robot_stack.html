Line upon Line

From rotation matrices to a robot that sees, decides, and acts.

“Line upon line, precept upon precept.” 2 Nephi 28:30

The course content builds up to one final project: a 4-joint simulated robotic arm that sorts parts off a moving conveyor using camera data and computer vision techniques. Each idea you learn is built with a tool, and each tool works with a part of the robot. Click any item to follow its path and learn more about the topic or tool.
