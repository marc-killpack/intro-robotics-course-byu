# HW09 faculty draft: planar visual feedback

This unreviewed draft asks students to calculate a planar velocity command,
write a short feedback law using supplied solve/limit helpers, analyze a
fixed-camera simulation, and explain a tool-mounted camera's changing frame.

The student controller scaffold, detection interface, solver/limit utilities,
and simulation activity described in the handout are **not yet prepared**.
The existing [stationary and moving faculty pilots](../../design/new-pilots.md)
use simplified NumPy image detection and are not stripped student exercises.
HW09 is not included in the current student manifest.

See [the proposed boundary map](../../../HOMEWORK_MAP.md),
[faculty reference](../../../instructor/HW09_REFERENCE.md), and
[improvement list](../../../instructor/IMPROVEMENTS.md). Build for review:

```text
python docs/homework/build_pdfs.py hw09 --render
```

Faculty review, student workload trials, supporting code/data, and a separately
reviewed student-release boundary remain open.
