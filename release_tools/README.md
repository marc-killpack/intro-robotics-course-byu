# Student release workflow (planned)

The current repository is an instructor working tree. Before the first
student publication, add a release tool that copies an explicit allowlist
into a new directory and inspects that copy for instructor-only material.
Keep the Docker and student workspace files in the allowlist. Follow the
reviewed release approach in `byu_robotics_hw_key/release_tools` as a model;
do not copy that tool without adapting its paths and course boundaries.
